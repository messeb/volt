## Getting Help

1. Check the documentation and examples.
2. Search [existing issues](https://github.com/messeb/volt/issues).
3. Ask in [GitHub Discussions](https://github.com/messeb/volt/discussions).
4. For confirmed bugs, use the bug report template.

Security vulnerabilities must be reported privately through
[GitHub Private Vulnerability Reporting](https://github.com/messeb/volt/security/advisories/new).

Volt is community-supported. Commercial support is not currently offered.
